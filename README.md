# Hospital Management System 🏥

A desktop-based enterprise application built using Core Java, Swing/AWT, and JDBC to streamline hospital administration, patient admissions, and staff management.

## 🚀 Key Features
- **Patient Management:** Add, update, and search patient details, assigned wards, and discharge summaries.
- **Doctor & Staff Directory:** Manage medical staff, department assignments, and availability schedules.
- **Emergency & Ambulance Tracking:** Integrated module to manage ambulance availability and emergency dispatch.
- **Secure Authentication:** Role-based login system for administrators and reception staff.
- **Database Connectivity:** Centralized data storage using JDBC and relational database tables.

## 🛠 Tech Stack
- **Language:** Java (JDK 8+)
- **GUI Framework:** Java Swing & AWT
- **Database Connectivity:** JDBC (Java Database Connectivity)
- **Database:** MySQL / Relational DB
- **IDE:** IntelliJ IDEA / Eclipse
